당첨자 아이디 넣기

방법 A — 엑셀 업로드: 아티스트(또는 멤버) 열과 아이디(또는 ID) 열, 이름(또는 성명·닉네임) 열이 있으면 자동 인식합니다. 폰 열이 있으면 그 번호대로, 없으면 순서대로 30명씩 나눕니다. 시트가 여러 개면 시트 이름을 아티스트로 씁니다.
방법 B — 붙여넣기: 엑셀에서 아티스트 | 아이디 | 이름 열을 복사해 그대로 붙여넣거나, 한 줄에 아이디 이름(띄어쓰기로 구분)만 붙여넣고 아래에서 아티스트를 고르세요. 이름이 없으면 아이디만 넣어도 됩니다.

자동입력 매크로 (안드로이드 + PC)

PC에 USB로 연결한 안드로이드 폰에서 친구 추가 → 아이디 입력 → 추가 → 이름 변경을 한 명씩 자동으로 반복합니다. 동작 순서는 아래에서 직접 짤 수 있어서 카카오톡·라인 모두 쓸 수 있어요. (아이폰은 안 됩니다)
  1. PC (처음 한 번): Android Platform-Tools를 받아 압축을 풀고, 이 도구에서 받은 .bat 파일을 그 폴더(adb.exe가 있는 곳)에 넣습니다.
  2. 폰 (처음 한 번): 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 개발자 옵션에서 USB 디버깅과 포인터 위치를 켭니다.
  3. 한글 이름까지 넣으려면 (처음 한 번): ADBKeyBoard의 ADBKeyboard.apk를 받아 platform-tools 폴더에 넣고, 명령 프롬프트에서 adb install ADBKeyboard.apk 를 실행합니다. 매크로가 시작할 때 이 키보드로 바꾸고, 끝나면 원래 키보드로 돌려놓습니다.
  4. 좌표 적기: 포인터 위치가 켜져 있으면 화면을 누를 때 맨 위에 X: 540 Y: 1200 처럼 좌표가 보입니다. 앱에서 실제로 한 명을 손으로 추가해 보면서, 누르는 곳마다 좌표를 아래 단계에 적으세요. 같은 기종이면 한 번만 적으면 됩니다.
  5. 먼저 🧪 1명 테스트로 확인하고, 잘 되면 폰 전체(30명) 파일을 받아 실행하세요.
⚠ 카카오·라인은 약관에서 자동화 프로그램 사용을 금지하고 있고, 짧은 시간에 아이디 검색을 많이 하면 검색 제한이나 계정 제재를 받을 수 있습니다. 한 명당 대기 시간을 넉넉히 두고(3초 이상 권장), 처음에는 적은 인원으로 시험해 보세요.

동작 순서

한 명마다 위에서 아래로 실행됩니다. 시작 화면(예: 카톡 친구 탭)에서 시작해서, 마지막에 다시 시작 화면으로 돌아오도록 짜면 됩니다. 기본 틀은 예시이니 앱 화면에 맞게 순서·좌표를 고치세요.

폰별 시리얼 번호 (선택)

여러 대를 한 PC에 동시에 꽂을 때만 필요합니다. 명령 프롬프트에서 adb devices 를 치면 나오는 값을 붙여넣으세요. 한 대씩 바꿔 꽂으며 하면 비워 두세요.
