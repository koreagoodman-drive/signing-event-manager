당첨자 아이디 넣기

방법 A — 엑셀 업로드: 아티스트(또는 멤버) 열과 아이디(또는 ID) 열이 있으면 자동 인식합니다. 폰 열이 있으면 그 번호대로, 없으면 순서대로 30명씩 나눕니다. 시트가 여러 개면 시트 이름을 아티스트로 씁니다.
방법 B — 붙여넣기: 엑셀에서 두 열(아티스트 / 아이디)을 복사해서 그대로 붙여넣거나, 아이디만 붙여넣고 아래에서 아티스트를 고르세요. 한 줄에 하나씩, 또는 쉼표·공백으로 구분해도 됩니다.

ADB 자동입력이란?

PC에 USB로 연결한 안드로이드 폰에 아이디 입력 → 등록 버튼 누르기를 자동으로 반복시키는 방식입니다. 폰 1대당 30명이 수십 초 안에 끝납니다. (아이폰은 지원되지 않습니다)
  1. 처음 한 번만: PC에 Android Platform-Tools를 받아 압축을 풀고, 받은 .bat 파일을 그 폴더(adb.exe가 있는 곳)에 넣으세요.
  2. 폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호 7번 탭 → 개발자 옵션 켜기 → USB 디버깅 켜기.
  3. 개발자 옵션의 포인터 위치를 켜면 화면 위쪽에 터치 좌표(X, Y)가 보입니다. 영상통화 앱의 아이디 입력칸과 추가/등록 버튼을 눌러 좌표를 아래에 적으세요. (폰 기종이 같으면 한 번만 적으면 됩니다)
  4. 폰을 USB로 연결하고 "USB 디버깅 허용"을 누른 뒤, 앱에서 당첨자 등록 화면을 띄워 놓고 .bat 파일을 더블클릭하세요.
  5. 폰을 여러 대 동시에 연결했다면 adb devices로 나온 시리얼 번호를 각 폰에 적어 주세요. 한 대씩 꽂아서 하면 비워 둬도 됩니다.

입력 동작 설정

아이디 한 명마다: ① 입력칸 탭 → ② (선택) 기존 글자 지우기 → ③ 아이디 입력 → ④ 등록 버튼 탭 또는 엔터 → ⑤ 대기

폰별 시리얼 번호 (선택)

여러 대를 한 PC에 동시에 꽂을 때만 필요합니다. 명령 프롬프트에서 adb devices 를 치면 나오는 값을 붙여넣으세요.
